# 江西省补贴性线上职业技能培训管理平台 · 自动刷课脚本

针对 [江西省补贴性线上职业技能培训管理平台](https://jiangxi.zhipeizaixian.com/)
的油猴脚本（兼容 Tampermonkey / ScriptCat 脚本猫）。

## ✨ 功能

- 🎬 **自动连播**：自动进入下一节，完整播放到结束才切课（不提前跳课）
- 🔇 **强制静音**：覆盖 muted / volume 属性，兼容 AliPlayer 等播放器
- 🤖 **验证码自动识别**：弹出「人机验证」时自动识别并填写——
  - 5 位数字验证码 → 自动识别数字串
  - 加减乘除算式（1~10）→ 自动计算结果
  - 识别失败自动「换一张」重试，答错重试，全程保留人工兜底
- 📋 **播放记录**：今日累计时长、各小节时长、验证暂停/恢复日志，
  每天自动重置、历史保留 30 天，可导出/复制
- 🎛️ **控制面板**：右下角悬浮面板，随时开关各项功能

## 📦 安装

### 第一步：安装脚本

1. 安装油猴扩展：
   - [Tampermonkey](https://www.tampermonkey.net/)（Chrome / Edge / Firefox）
   - 或 [ScriptCat 脚本猫](https://docs.scriptcat.org/)（国内访问更友好）
2. 安装本脚本（任选其一）：
   - **GitHub**：点击本仓库的
     [`zhipei-auto-study.user.js`](zhipei-auto-study.user.js) 原始文件，
     油猴会弹出安装确认；
   - **手动**：复制 [`zhipei-auto-study.user.js`](zhipei-auto-study.user.js)
     的全部内容 → 油猴「新建脚本」→ 粘贴 → 保存。
3. 打开课程页面，右下角出现「🎧 自动刷课」面板即安装成功。

### 第二步：启动本地识别服务（自动验证必需）

脚本的自动识别依赖一个**本机运行**的 OCR 服务（识别在本地完成，验证码图片不离开你的电脑）。

- 不想装 Python？直接下载 [Releases](../../releases) 里的
  `识别服务-win64.zip`，解压双击 `启动识别服务.exe`；
- 或按 [`server/README.md`](server/README.md) 用 Python 运行。

> 不启动服务也能用脚本，只是遇到验证时暂停等人工处理。

## 🔧 工作原理

```
平台弹出验证 → 脚本暂停视频 → 截取验证码图片
  → POST 到本机 127.0.0.1:8765 → 本地 OCR（ddddocr+RapidOCR）
  → 填答案 → 点确定 → 恢复播放
```

识别细节见 [`server/README.md`](server/README.md)。

## ❓ 常见问题

- **提示「自动识别异常，检查本地识别服务」**：识别服务没启动；
  先双击 `启动识别服务`（Windows 记得看防火墙提示，允许访问）。
- **识别出错**：把服务窗口的 `[OCR] ...` 日志和验证码截图
  发到 [Issues](../../issues)，格式为
  `平台验证码图 + [OCR] 日志`，便于定位。
- **平台改版导致失效**：脚本选择器基于平台当前前端结构，
  平台改版后可能失效，欢迎提 Issue 或 PR。
- **想关掉自动识别**：面板「自动验证」开关关掉即可。
